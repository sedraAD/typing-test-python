# Typing Practice Application (Python)

This project is a menu-based Python application that allows users to practice typing using text files of different difficulty levels.
The program provides an interactive command-line interface where users can choose between easy, medium, and hard typing exercises, view scores, or try a random character typing test.

The project was developed as part of a Python programming course and focuses on practicing file handling, modular programmingand user interaction.

## Features

- Typing practice with multiple difficulty levels (easy, medium, hard)
- Random character typing test
- Menu-based command-line interface
- Score tracking
- Modular structure with separate files for different functionality

## Project Structure

```bash
.
├── main.py                # Main program and menu logic
├── typing_test.py         # Functions for typing tests
├── random_char_test.py    # Random character typing functionality
├── easy.txt               # Easy difficulty text
├── medium.txt             # Medium difficulty text
├── hard.txt               # Hard difficulty text
├── score.txt              # Score text file
```

## How to Run

1. Make sure you have Python 3 installed.
2. Clone the repository or download the files.
3. Navigate to the project directory.
4. Run the program:

```bash
python main.py
```

5. Follow the menu instructions in the terminal.
